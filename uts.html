Tentang Kegiatan

Seminar Nasional Teknologi Web merupakan agenda tahunan Fakultas Sains dan Teknologi Informasi untuk membekali mahasiswa dengan standar pengembangan web modern yang aksesibel, responsif, serta menerapkan semantic HTML dan CSS Flexbox secara tepat guna.

Syarat Peserta

  • Mahasiswa aktif program studi Teknik Informatika atau Sistem Informasi.
  • Membawa laptop pribadi dengan peramban modern dan editor kode terpasang.
  • Mengisi formulir pendaftaran daring sebelum kuota ruangan terpenuhi.
